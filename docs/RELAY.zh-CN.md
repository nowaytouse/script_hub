# 订阅管理

[English](RELAY.md) · [简体中文](RELAY.zh-CN.md)

1. 在资料库添加**订阅**或**集合**。订阅支持 HTTPS 链接、Gist、粘贴节点及本地节点文件。
2. 编辑参数和有序操作。原生预设会追加可编辑步骤，不执行 Entrance 的 JavaScript，也不声称完整复现其全部功能。
3. 预览。仅整理使用 Rust；可选的协议级测活使用另行检测到的内核。
4. 输入具备 Gist 权限的令牌并上传。输出留空可新建秘密 Gist，也可选择已有的独立目标。
5. 定时更新时，确认上传授权、选择间隔并启用同步。可重复操作会应用于每次新下载；绑定旧节点位置的单项修改不能用于远程来源的定时任务。

管理器独立运行，无需 Surge 模块或本地服务器。客户端节点格式只是适配目标，不是运行依赖。

使用 Surge 时，选择 Surge 格式发布，再给已验证的策略组命名并复制到 `[Proxy Group]`。请勿公开订阅链接。

保存加密资料库后可跨启动保留；应用使用本机固定私有位置，不保存密码或 Gist Token。切换条目前会保护未保存草稿；被集合引用的订阅须先移出集合再删除。

可在「输出」为每个条目设置目标 Gist、文件名、标题和同步间隔，再保存加密资料库。令牌、授权和正在运行的计划不会恢复。远程订阅的定时同步会重新获取来源，不沿用资料库缓存。已知的来源 Gist（包括集合成员的来源）不能同时用作发布目标。

集合按选择顺序合并为 sing-box 节点 JSON。**更新并生成**下载远程成员，**使用缓存生成**保持离线。定时同步会下载远程成员，并沿用本地成员。失败时不会部分替换缓存。

导入 Sub-Store JSON/Base64 备份后可选择**将可用项目加入资料库**。已有条目不会被覆盖；成员引用不完整的集合会整组跳过并计数。按标签选中的成员会按备份顺序追加到明确指定的成员之后，保存为固定列表。兼容的协议筛选和简单名称筛选会转为原生操作。迁移的集合名称筛选匹配成员各自处理后的名称，不含集合前缀，也不受集合级改名影响。遇到不支持的启用步骤，其后的操作也不再迁移，避免改变原意。不恢复脚本、设置或令牌；加入资料库时不下载远程链接。

订阅级 **正则重命名**和**正则删除**支持迁移成可编辑的批量重命名：模式支持字面分支、外层锚点、非嵌套捕获组和 ASCII 大小写折叠。替换支持普通文本、`$$`（美元符号）、`$&`（完整匹配）和 `$1`、`$10` 等有效的编号捕获组。每条规则替换全部匹配项，然后去掉名称首尾空白。集合级重命名及其他 JavaScript 专用正则或替换语法暂不迁移。

订阅级的**移除旗帜**也可迁移：删除节点名称任意位置的国旗、海盗旗和彩虹旗，再去掉首尾空白。添加旗帜不迁移。

**名称排序**可迁移 UTF-16 升降序，同名节点保留输入顺序，不迁移随机排序。资料库预览不再默认追加名称装饰或排序。

**正则排序**可按优先级迁移兼容模式，未匹配节点遵循原配置的升序、降序或原始顺序。迁移的集合排序使用添加 Script Hub 前缀之前的成员名称比较，不会移除输出名称的前缀。**快速设置**可迁移 UDP、TCP Fast Open 和显式启用证书验证；若还包含其他启用字段（包括跳过证书验证），不会只迁移其中一部分。

经典 age X25519 备份可用私钥解锁。加密导出使用 `age1…` 接收方公钥包装 Hub 备份，请另行保管对应私钥。密钥不保存。不支持口令、SSH、插件或后量子 age 格式。限制：密文 8 MiB，解密后 4 MiB，解码后的头部 8 KiB。

Rust age 库尚未达到 1.0，上游标为实验性。重要配置请另留一份可恢复副本。

**Rhai 脚本**支持 `transform(node)`、`transform(node, context)`、`operator(nodes, context)` 和 `filter(nodes, context)`。整组入口最多接收 4,096 个节点。操作器返回有序子集；筛选器为每个输入节点返回一个布尔值，不修改节点内容和顺序。可用字段和正则函数见编辑器。预览前先选择 Gist 格式；集合成员按 sing-box 格式处理后再合并。脚本有资源限制，但不是进程级隔离，不能读取凭据、文件或访问网络。请在预览前检查导入的脚本：改写服务器后，客户端连接时可能把已有凭据发往新服务器。不执行 JavaScript。

通过 `context.arguments` 读取本步的文本参数，请勿填入凭据。来源上下文提供来源类型、可用的本地显示名，以及处理集合成员时从 1 开始的序号。将 `node.underlying_proxy` 设为保留节点的最终名称可建立链路，设为 `()` 可清除；循环和悬空引用会阻止导出。DoH 和测活沿用原生操作；单节点探测不会绕过代理链。

计划仅在应用运行期间执行，同时只运行一个任务。**立即同步**可提前执行已启用的计划，不会跳过冷却。默认 60 分钟，范围 1 分钟至 7 天；不补跑积压任务。写入结果不确定时停止，内容无变化不上传。最新成功结果会成为复制、导出的内容。

凭据只保留在会话，不写入设置或历史。退出、清除会停止计划；停止后需明确重新启用。秘密 Gist 不代表加密，取消也不能撤销已被接受的写入。

HTTPS 导入限制为 4 MiB，使用严格 TLS 和公网目标，不跟随重定向，不向外部网站发送 GitHub 凭据。无法证明第三方镜像不指向输出 Gist；重新读取也不等于与来源服务器或 GitHub 的原子事务。输入脚本不会执行。

拒绝具有外部执行、插件或文件加载能力的节点指令。可选测活会固定已校验的公网地址；无法安全保留传输或 DNS 语义的节点保持未知。未知不代表可用或安全。
